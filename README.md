# Portfolio DigiOne / Marketing Digital

Site web statique en HTML, CSS et JavaScript pour présenter mes services, mon parcours et mes offres.

## Débogage local dans Chrome

Dans VS Code, ouvrez le menu **Exécuter et déboguer**, sélectionnez **Launch Chrome**, puis appuyez sur `F5`. La configuration ouvre directement `index.html` et ne nécessite pas de serveur local.

## Déploiement GitHub Pages

1. Créez un dépôt GitHub vide.
2. Poussez ce dossier sur la branche `main`.
3. Dans GitHub, ouvrez les paramètres du dépôt puis allez dans **Pages**.
4. Choisissez **Build and deployment** → **GitHub Actions**.
5. La publication se fera automatiquement après chaque push sur `main`.

Votre site sera disponible à l’adresse :
https://<votre_nom_utilisateur>.github.io/<nom_du_dossier>/
